# Repository guidelines

- Do not add or commit copyrighted WAD or DEH game data; keep them user-supplied on the Vita.
- Do not import unrelated changes from the original Chex Quest 3 workspace.
- Keep the shared Vita controls consistent: D-pad Up quicksave, Down quickload, Left/Right weapon cycling for all games.
- Preserve separate save and settings directories for CQ1, CQ2, and CQ3.
- Reply to project questions in Italian unless asked otherwise.
